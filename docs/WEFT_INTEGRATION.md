# Optional Weft integration boundary

This is a public summary of Confidence's integration boundary. Private operator paths, coordination records and confidential source are not distributed. Its source/output correspondence is recorded in the public source manifest; this summary does not replace original evidence.

Weft is an optional private dependency, unavailable in this source distribution. The repository includes Confidence's adapters, protocol consumers, synthetic wire fixtures and explicit guards for the real-source qualification lane. It includes no Weft implementation, private bundle, checkout, daemon state or credential. The supported local scripted demo and signed verifier example need no Weft source.

The bounded fixture handoff distinguishes the live workspace from an exact retained revision and root. Submission freezes its project, incarnation, base, policy, identity, revision/root and request bytes. Current authorization is checked before admitting source, and uncertain recovery preserves the original command. Retained source does not change because the live workspace advances.

The additive byte-profile consumer verifies exact binary/text bytes, modes, complete retained roots, profile/privacy binding and bounded batches. Synthetic fixtures establish their declared wire contract. They do not establish a deployed producer, guarded editor writes, peer-disk convergence or a full-repository release.

A separately authorized real-source rehearsal must pin the implementation, dependency closure and tool environment; report unavailable or missing inputs honestly. A finite local rehearsal is distinct from production-container, model, two-machine and full-repository qualification. The repository execution recipe remains unregistered, and optional source availability grants no authority to enable it.
