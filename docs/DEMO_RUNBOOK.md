For the controlled interruption, install a one-shot browser `fetch` interceptor for the exact deployed `/v1/projects/<project>/prepare-review` POST **after** a current snapshot. It must call the original fetch, observe HTTP 202, restore the original fetch and then throw a transport error to the app. Retain the observed status and exported command record. Read the authority before retrying to confirm one prepared review, then choose **Recover same command** and verify that the same ID/body/revision was replayed with no second review. A request blocked before it reaches the server is weaker evidence and must be labelled that way. If the browser reports a definitive rejection instead of **UNKNOWN**, narrate that result. Do not use the local **Simulate a lost publication response** control as live evidence; it is available only in the scripted runtime. The [publication integration](ARTIFACTS_INTEGRATION.md) has a separate unknown-effect and readback gate.

For this pilot, arm the one-shot interceptor in the authenticated page's browser console immediately before clicking **Prepare review**. It observes only the response status; it does not log the command body or credentials. A page reload disarms it if the button is never clicked.

```js
(() => {
  const originalFetch = window.fetch;
  const target = '/v1/projects/competition-demo-r2/prepare-review';
  window.fetch = async (input, init) => {
    const url = new URL(input instanceof Request ? input.url : String(input), location.href);
    const method = String(init?.method ?? (input instanceof Request ? input.method : 'GET')).toUpperCase();
    if (method !== 'POST' || url.origin !== location.origin || url.pathname !== target) {
      return originalFetch.call(window, input, init);
    }
    try {
      const response = await originalFetch.call(window, input, init);
      console.info('Confidence controlled review acknowledgement:', response.status);
      if (response.status === 202) throw new TypeError('Controlled browser response loss after HTTP 202');
      return response;
    } finally {
      window.fetch = originalFetch;
    }
  };
})();
```
